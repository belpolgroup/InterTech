Конспекты

Тема 1: Введение в HTML
HTML используется для описания структуры и содержимого веб-страницы с помощью элементов и их атрибутов. Базовый HTML5-документ содержит объявление типа документа, элементы html, head и body, а правильная вложенность элементов помогает браузеру корректно интерпретировать страницу.
Тема 2: Семантическая разметка
Семантические элементы описывают не внешний вид блока, а его смысл и назначение в структуре документа. Использование header, nav, main, section, aside и footer делает HTML понятнее для разработчиков, браузеров и вспомогательных технологий.
