# InterTech

Учебный репозиторий для выполнения практических и домашних работ по дисциплине "Интернет-технологии".

## О проекте

В репозитории размещаются учебные задания по веб-разработке. Каждая домашняя работа хранится в отдельной директории, а связанные практические работы - во вложенных каталогах.

На текущем этапе курса используются:

- HTML
- CSS
- Git
- GitHub

JavaScript будет добавлен после изучения соответствующей темы.

## Homework 01

Первая учебная HTML-страница с краткой информацией об авторе и мотивации изучения веб-разработки.

## Homework 02

Домашняя работа объединяет две практические работы.

### Практическая работа 1-1 — "Страница о стране"

Вариант: **Египет**.

Реализовано:

- базовая структура HTML5;
- заголовок страницы и логические секции;
- нумерованный и маркированный списки;
- внешние гиперссылки;
- ссылка `mailto:`;
- подключён отдельный файл `styles.css`.

### Практическая работа 1-2 — "Мои курсы"

Реализовано:

- семантическая структура: `header`, `nav`, `main`, `section`, `aside`, `footer`;
- все три вида списков: `ol`, `ul`, `dl`;
- якорная навигация по разделам страницы;
- список дисциплин первого семестра;
- внешние образовательные ресурсы с открытием в новой вкладке;
- ссылка `mailto:`;
- секция "Расписание" с временной текстовой заглушкой;
- дополнительная страница `about.html`;
- относительные ссылки между `index.html` и `about.html`;
- временное локальное изображение профиля.

Файлы `styles.css` на текущем этапе оставлены пустыми намеренно: оформление будет добавляться по мере изучения CSS.

## Проверка

Перед сдачей HTML-файлы проверяются через W3C Markup Validation Service. Итоговая версия работы должна проходить проверку без ошибок.

Также необходимо проверить в браузере:

- переходы по якорным ссылкам;
- переходы между `index.html` и `about.html`;
- открытие внешних ссылок;
- работу ссылки `mailto:`;
- загрузку локального изображения профиля.
