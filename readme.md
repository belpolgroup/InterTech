# InterTech

Учебный репозиторий для выполнения практических и лабораторных работ по веб-разработке.

## О проекте

В репозитории размещаются учебные задания, примеры и практические работы, выполняемые в рамках обучения.

Основные технологии:

* HTML
* CSS
* JavaScript
* Git
* GitHub

По мере прохождения курса список технологий может расширяться.

## Структура репозитория

```text
InterTech/
├── homework-01/
│   └── index.html
├── practice-02/
└── README.md
```

Каждая практическая или лабораторная работа размещается в отдельной директории или оформляется в соответствии с требованиями задания.
